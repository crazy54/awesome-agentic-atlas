How these 50 were chosen

Every category gets slots in every day, weighted by the square root of its size — so the 14 categories here are all represented, the largest one does not take half the page, and a category with a few dozen projects in it is not crowded out by one with thousands. Within a category, the projects that have gone longest without appearing go first. Stars are not an input: the front page already ranks by them, and a Discover that consulted them would be the front page with a different heading.

The week's seven days are picked at once, on Sunday, and written to discover.json — so today's 50 are the same 50 for everyone, they can be linked to, and they are still here when you come back this afternoon. The day turns over at midnight, Chicago time.

daily·weekly·tests·deployed·Build status is fetched from GitHub when the page loads.
50 of 10,451 projects a day, rotated so the whole atlas comes round rather than the popular end of it being resampled. Stars, language and last-push come from the GitHub API on 2026-10-13 and drift daily; the picks are fixed for the week. Everything here is also in the searchable index, on each project's own page, and in the Markdown edition.
