    The atlas, as a map
    Every entry came from someone else's curation work; all 39 source lists are credited in the repository. Stars, language, licence and last-push come from the GitHub API on 2026-09-22 and drift daily. Platform verdicts are derived from each project's own README, install route, CI config and release assets — green ✓ is stated evidence, amber ? is inferred from the language, and grey ✗ is neither. The glyph says the same thing the colour does, so the column still reads in greyscale, in print, and with a colour-vision deficiency. A push date underlined like this means nothing has landed in that repo for over a year. A dash in the star column means the row is a folder inside someone else's repo, or a dead link, and has no count of its own.
